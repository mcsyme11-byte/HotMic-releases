Privacy Policy

Effective October 30, 2026

Hot Mic processes speech entirely on the user's own computer. Audio and dictated text are never uploaded, sold or shared. Hot Mic has no accounts, no analytics and no advertising.

This policy explains what information Hot Mic, the dictation application for Windows and Mac developed by Malcolm Syme ("the developer"), handles, and how. It also covers this download website.

1. Speech and dictated text

  • On-device processing. Speech recognition (NVIDIA Parakeet and, where a suitable graphics card is present, OpenAI Whisper) and text cleanup (SpeakoFlow Mini) run locally on the computer. No audio or text is sent to the developer or to any other party.
  • No storage by default. Recordings are held in memory only while they are being processed and are then discarded.
  • Optional test recordings. If the user turns on Keep test recordings (Settings › Advanced, off by default), the last 20 dictations (audio and resulting text) are stored on the computer to help diagnose recognition problems. They are never transmitted and can be deleted at any time from the same screen.

2. Information stored on the computer

  • On Windows, settings (including the user's custom words) are stored in %APPDATA%\HotMic, and the AI models and a log file in %LOCALAPPDATA%\HotMic.
  • On a Mac, settings, the AI models and the log file are stored in ~/Library/Application Support/HotMic.
  • The log records technical events (for example, timings and microphone levels) and never contains dictated text unless the user turns on the Detailed log option for troubleshooting.
  • This information remains on the computer. Uninstalling Hot Mic removes the application; settings and models may be deleted manually from the folders above.

3. Network connections

Hot Mic connects to the internet only for the following purposes:

  • Downloading the AI models once, from Hugging Face (huggingface.co), when they are first needed or when the user requests a repair.
  • Checking for updates (installed copies on Windows only), from GitHub (github.com), at most every 12 hours. These requests contain no personal information. The Mac test version does not check for updates.

Like any internet request, these connections reveal the computer's IP address and basic technical details (such as the application name and version) to the service contacted. Those services handle such data under their own privacy policies: Hugging Face and GitHub.

4. Operating system components

On Windows, Hot Mic uses components built into Windows, including Microsoft Edge WebView2 (to display its settings windows) and Microsoft Defender SmartScreen (which checks downloaded files). These components are operated by Microsoft and are subject to the Microsoft Privacy Statement.

On a Mac, Hot Mic uses macOS's own clipboard, sound and voice functions, and macOS's permission system (Microphone and Accessibility), which the user controls in System Settings › Privacy & Security. These are subject to Apple's Privacy Policy.

5. This website

This website is hosted by GitHub Pages. It uses no cookies, analytics or tracking scripts. GitHub may log visitors' IP addresses for security purposes, as described in the GitHub Privacy Statement.

6. Children

Hot Mic does not knowingly collect information from anyone, including children, because it does not collect personal information at all.

7. Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date. Material changes will also be noted in the release notes.
